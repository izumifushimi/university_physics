## 通用约束（每个任务都要遵守）

```
- 纯静态站点，无构建步骤。改完内容后运行：
    cd <项目根目录>
    node tests/audit.js            # 内容一致性、字段完整性、渲染、搜索
    node tests/check-tex.js        # TeX 反斜杠与 $ 配对
    node tests/build-standalone.js # 重新生成 site/大学物理学习站-单文件版.html

- 写 TeX 时的铁律：
  * 普通字符串字面量里，TeX 必须写双反斜杠：'$\\Delta x$'
  * String.raw`...` 里写单反斜杠：String.raw`$\Delta x$`
  * 公式里不要用撇号 '，会截断 JS 字符串。用 ^{\prime} 或换字母
  * 反斜杠加字母容易被吞：\t (\tau \text \times)、\b (\beta \bar)、
    \v (\vec)、\f (\frac)、\n (\nu \nabla)

- 每改一个 .js 文件都跑 node --check 确认语法
- 不要引入第三方依赖，不要改成需要打包的工程
- 未完成的功能要在界面上明确标「待更新」，不要留空按钮或假装已完成
```
